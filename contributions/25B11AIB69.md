## Three Git Commands and Their Uses

1. `git init`  
   Initializes a new Git repository in the current folder.

2. `git add .`  
   Stages all changes so they are ready to be committed.

3. `git commit -m "message"`  
   Saves the staged changes permanently in the repository history with a message.

## Purpose of GitHub

GitHub is a platform that hosts Git repositories online. It allows developers to store code, collaborate with others, track changes, and manage projects through features like pull requests, issues, and version history.

## One Benefit of Using Branches

Branches allow us to work on new features or experiments without affecting the main codebase. This keeps the main branch stable while development continues separately.
